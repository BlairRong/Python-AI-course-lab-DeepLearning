## Common Issues and Solutions

### Issue 1: "RuntimeError: Numpy is not available"

**Cause**: Kernel state corruption or missing numpy
**Solution**:
```python
# Restart kernel: Kernel → Restart Kernel
# Then run Cell 1 again to reinitialize
# Make sure to add: import numpy as np
```

### Issue 2: "FileNotFoundError: data.yaml not found"

**Cause**: Haven't run Cell 4 yet
**Solution**: Run cells in order (1, 2, 3, 4, 5, 6...)

### Issue 3: "CUDA out of memory" (if using GPU)

**Cause**: Batch size too large
**Solution**:
```python
# In training cell, change:
batch=8  # Reduce from 16 to 8 or 4
device='cpu'  # Or use CPU instead
```

### Issue 4: Training very slow

**Cause**: Normal on CPU, or too large batch size
**Info**:
```
CPU Training Speed (YOLOv8n): ~2-4 hours for 10 epochs
GPU Training Speed: ~10-20 minutes for 10 epochs

To speed up:
- Reduce epochs: 10 → 5
- Reduce image size: 416 → 320
- Reduce batch: 8 → 4
```

### Issue 5: Model accuracy very low

**Cause**: Small dataset (150 images), underfitting
**Solution**:
```python
# Increase training time:
epochs=30  # More epochs for small dataset

# Better augmentation already enabled
# Consider: Collect more data (500+ images)
```

### Issue 6: Webcam not working

**Cause**: Camera not accessible or wrong device
**Solution**:
```python
# Check available cameras:
import cv2
for i in range(5):
    cap = cv2.VideoCapture(i)
    if cap.isOpened():
        print(f"Camera {i} available")
    cap.release()

# Then use the correct camera number:
run_detector_on_video(model, video_source=0)  # Change 0 to working camera
```

## Performance Optimization

### For Faster Training

```python

# Or reduce image size:

```

```python

# More data:

# Already enabled in ultralytics
```
