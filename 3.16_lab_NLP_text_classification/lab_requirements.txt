Machine Learning Lab – Text Classification

Goal

You will learn how to:

Part 1 – Build the Classifier
In machine learning, text must first be converted into numbers before a model can learn from it.
Use CountVectorizer to transform the text into numerical vectors.
Then train a classifier that can predict whether a review is Positive or Negative.
 
You may use tools from scikit-learn, for example:
CountVectorizer
SVC

Part 4 – Understanding the Limitations
Your current model uses a very simple approach called bag-of-words.
This means the model only knows which words appear in the text, but it does not truly understand the meaning of the sentence.
 
Test your model with the following sentences:
 
"the movie was not good"
"the acting was not bad"
"visually impressive but boring"
"i wanted to like it"
Then answer the following questions:
 
Which of these sentences were classified incorrectly?
Why might the model struggle with sentences that contain negations like "not good" or "not bad"?
Why might sarcasm or mixed opinions be difficult for this type of model?
What information about the sentence meaning is lost when we only count words?
